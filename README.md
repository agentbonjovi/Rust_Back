# Rust_Back

Проект содержит Rust-анализатор селективности предикатов и локальное приложение для просмотра результатов.

## Что делает `main.rs`

Основная логика находится в [src/main.rs](/Users/r2d2/Documents/GitHub/Rust_Back/src/main.rs).

Программа:

1. читает CSV-файл;
2. выделяет числовые столбцы;
3. считает по ним статистику:
   `count`, `mean`, `std`, `min`, `max`, `unique_values`, тип данных и вид распределения;
4. строит гистограммы по столбцам;
5. генерирует набор предикатов селективности для каждого числового столбца:
   `Eq`, `Lt`, `Gt`, `Between`;
6. оценивает селективность тремя способами:
   `KNN`, гистограмма, приближённая эвристика;
7. сравнивает ошибки оценок;
8. рекомендует тип сканирования:
   `Index Scan`, `Seq Scan`, `Bitmap Scan`;
9. сохраняет итог в [ml_optimizer_knn_report.txt](/Users/r2d2/Documents/GitHub/Rust_Back/ml_optimizer_knn_report.txt).

Если переданный CSV не существует, backend может сгенерировать синтетический файл.

## Запуск backend из консоли

```bash
cargo run -- synthetic_data.csv
```

Или через уже собранный бинарник:

```bash
./target/debug/bac123 synthetic_data.csv
```

3. при необходимости разрешить запуск через Finder: `Control + click` → `Open`.

## Web-версия

Web-версия запускает тот же backend, но открывает интерфейс в браузере.

Запуск:

```bash
python3 gui_app.py --mode browser
```

Что произойдёт:

1. поднимется локальный сервер на `127.0.0.1:8765`;
2. откроется страница с интерфейсом;
3. из окна можно выбрать CSV, сгенерировать синтетический CSV, запустить анализ и посмотреть отчёт.

Если браузер не открылся автоматически, откройте вручную:

```text
http://127.0.0.1:8765
```

## Standalone web dashboard

```bash
python3 gui_app.py --mode local --dataset synthetic_data.csv
```

Этот режим создаёт локальный HTML-дашборд без сервера. Он полезен для просмотра уже готового отчёта, но не запускает backend из интерфейса.

## Что показывают графики

Интерфейс строит графики не по сырым данным CSV, а по результатам анализа селективности из отчёта backend.

`Средняя ошибка моделей`

- показывает среднюю ошибку для `KNN`, `Hist`, `Approx`;
- помогает быстро понять, какая модель оценки селективности точнее на данном CSV.

`Средняя селективность`

- показывает средние значения `Actual`, `KNN`, `Hist`, `Approx`;
- позволяет сравнить, насколько предсказанные селективности совпадают с реальными.

`Рекомендованные сканы`

- показывает, сколько раз backend рекомендовал:
  `Index Scan`, `Seq Scan`, `Bitmap Scan`;
- это визуализация итогового решения оптимизатора по всем сгенерированным предикатам.
